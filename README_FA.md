# آماده‌سازی بک‌اند سنسو

این پوشه محل طرح پایگاه داده مرکزی است. برای استفاده واقعی چندگوشی باید یک پروژه Supabase ساخته شود و مقادیر URL و کلید عمومی آن در برنامه‌ها تنظیم شوند.

## جدول‌های موردنیاز
- profiles: کاربران و نقش‌ها (owner, manager, cashier)
- products, categories: منو و قیمت‌ها
- tables: میزها و QR اختصاصی
- orders, order_items: سفارش و اقلام سفارش
- inventory_items, stock_movements: موجودی و گردش انبار
- expenses, settlements, sales_channels: هزینه‌ها و تسویه کانال‌ها
- audit_logs: ثبت تغییرات کاربران

## امنیت
- فعال‌سازی Row Level Security برای همه جدول‌ها الزامی است.
- صندوق‌دار فقط سفارش و فروش را ببیند/ثبت کند؛ دسترسی مالی و سود فقط برای نقش‌های مجاز باشد.
- کلید service_role هرگز داخل APK قرار نگیرد.
- برای جلوگیری از ثبت تکراری سفارش، شناسه یکتای درخواست (idempotency key) در سمت سرور بررسی شود.

تا پیش از ساخت پروژه Supabase و تنظیم سیاست‌های دسترسی، این اپ‌ها صرفاً رابط کاربری آزمایشی هستند و اطلاعات واقعی را بین گوشی‌ها همگام نمی‌کنند.
